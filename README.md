# 🌍 Угадай столицу

**«Угадай столицу»** — Telegram-бот для изучения географии в формате викторины. Пользователю предлагается определить столицу страны за ограниченное время, используя варианты ответов и подсказки.

Проект разработан на Python с использованием асинхронного взаимодействия с Telegram API и базы данных SQLite.

## ✨ Возможности

- 🌎 Викторина с вопросами о странах и их столицах.
- ⏱ Ограничение времени на ответ — 30 секунд.
- 💡 Подсказка с первой буквой названия столицы.
- 🗺️ Подсказка с картой.
- 🏳️ Отображение флагов стран.
- 📸 Получение дополнительной информации о странах.
- ⭐ Система опыта (XP) и уровней.
- 🔥 Отслеживание серии правильных ответов.
- 🏆 Система достижений.
- 👤 Личный профиль со статистикой.
- 🥇 Таблица лидеров TOP-10.
- ⚙️ Настройки подсказок и уведомлений.
- 🔄 Возможность сбросить игровой прогресс.

## 🛠 Используемые технологии

| Технология | Назначение |

| Python 3.14 | Основной язык программирования |

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/liizaaa/guess_the_capital_bot.git
```

Переход в папку проекта:

```bash
cd guess_the_capital_bot
```

### 2. Создание виртуального окружения

```bash
python3 -m venv .venv
```

Активация на macOS и Linux:

```bash
source .venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Добавьте необходимые API-ключи и настройки в соответствии с шаблоном `.env.example`.

Для работы бота необходимо получить токен Telegram-бота через [@BotFather](https://t.me/BotFather).

### 5. Запуск

```bash
python main.py
```

После запуска бот будет готов принимать сообщения в Telegram.

## 🗄 База данных

Для хранения информации используется SQLite и SQLAlchemy.

В базе данных сохраняются:
- данные пользователей;
- игровая статистика;
- результаты ответов;
- опыт и уровни;
- серии правильных ответов;
- полученные достижения;
- настройки пользователей.

## 🏗 Архитектура

Проект организован по модульному принципу:

- **Handlers** — обрабатывают команды, сообщения и нажатия на кнопки.
- **Services** — содержат основную бизнес-логику и взаимодействие с внешними API.
- **Models** — описывают структуру таблиц базы данных.
- **Keyboards** — отвечают за интерфейс взаимодействия с пользователем.
- **States** — управляют состояниями пользователя во время игры с помощью FSM.

Такое разделение упрощает сопровождение проекта и позволяет добавлять новые функции без существенного изменения существующего кода.
